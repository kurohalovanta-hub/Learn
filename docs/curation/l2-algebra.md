# l2-algebra — Algebra Repair (Test-Out Loop)

Concept:
Restore fluent symbolic manipulation — equations, factoring, fractions with variables,
exponent and logarithm rules, small linear systems — by DIAGNOSING what is actually broken
and patching only that. This node is a repair loop, not a course: Khan Academy Course
Challenges are the diagnostic instrument; units are opened only on demonstrated failure.
Log/exponent fluency is the explicit priority (log rules = how loss curves and learning-rate
schedules are read for the next 200 days).

Learner prerequisites:
Grade-10 math baseline (safe per §3); no programming needed. This is the root node of the
math track — nothing in-app gates it. Requires only a free Khan Academy account so Course
Challenge results persist.

What beginners commonly misunderstand:
- "I was bad at math" ≠ global deficiency; it is typically 8–15 specific broken skills the
  diagnostic will name precisely. Re-taking school linearly is the #1 time sink.
- Log rules memorized as arbitrary incantations instead of exponent laws read backwards
  (log(ab)=log a+log b IS a^m·a^n=a^(m+n)); fixing the direction of reading fixes retention.
- Fractional/negative exponents treated as new objects rather than notation for roots/reciprocals.
- Distribution errors under pressure: (a+b)² → a²+b²; dividing both sides by an expression
  that can be zero (silently dropping solutions).
- Recognition vs mastery: re-watching explanations feels like repair; only cold retrieval
  under time pressure is repair (this learner's flagged risk).

- PRACTICE: Patch loop, ~2–8 h depending on diagnosis. Alg 1 failures: drill only failed

  AI-generated, unseen) in ≤20 min, ≥9/10; one miss = re-drill that skill only.

Why this won:
The cluster philosophy (HANDOVER §12: test out first) is not merely compatible with Khan —
Khan is the only free system with a persistent per-skill diagnostic (Course Challenge →
skill-level report → infinite generated practice on exactly the failed skills). Community
evidence is unanimous that adults over-estimate what they retained (HN 39047825) and that
problem volume, not video, is the repair mechanism (HN 20446796). The 2026 restructure was
verified live: classic Algebra 1/2 Course Challenge URLs are still in service, the 12-unit
Algebra 2 structure and the three target-unit URLs (:exp, :logs, :eq) were confirmed in
search results this session. OpenStax stays as the unseen final instrument so "mastery"
is never graded by the same system that trained it.

What was rejected (and why):
- Watching any lecture series (Professor Leonard-style, or Khan playlists linearly) —
  repair ≠ first learning; violates the test-out rule and the 14 h budget.
- Math Academy — community-praised diagnostics (HN 39047825) but paid, and its always-on
  spaced system is redundant with a 210-day plan that already schedules retention checks.
- AoPS books — first-principles depth is the wrong direction for repair (slow, expensive;
  same HN thread).
- Brilliant — reported out-of-sequence lesson structure for systematic gap-patching
  (HN 39047825).
- The new Illustrative-Mathematics Algebra 1 course as the diagnostic
  (https://www.khanacademy.org/math/algebra-1-illustrative-math/test/x6418b49dfbc9d0c9:course-challenge)
  — classroom-routine-oriented rebuild; the classic course's skill graph matches this node's
  patch list. Kept on file as the successor URL if the classic course is retired.
- ALEKS-style paid placement (seen in results via university placement pages) — solves the
  same problem as Khan's free challenge.

Risk of superficial understanding:
The Course Challenge samples skills — help-center threads reference challenges of 20+
questions [approx], far fewer than the course's skill count, so a lucky 85% can hide a
broken skill the challenge never drew. Mitigations already
in the packet: unit tests ≥90% on the three core Alg 2 units regardless of challenge score,
the OpenStax unseen test, and the timed mixed drill. Also: Khan's hint system can create
assisted-mastery illusion — hints used = skill not mastered (log it as a fail; HANDOVER
honesty rule: heavy-AI/hint-assisted caps below Gold).

Required active work:
Every minute is active by construction (test-out loop). Non-negotiables: the two cold
challenges in single sittings; ≥90% unit tests on :exp/:logs/:eq; the hand derivation of
log laws from exponent laws; the timed 20-equation drill; OpenStax closed-book prove-it;
day-7 retention set.
