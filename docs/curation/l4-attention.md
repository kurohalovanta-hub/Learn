# l4-attention — Attention From a Blank File

Concept: Scaled dot-product attention as content-based routing: every token emits a query, offers a key, and carries a value; softmax(QKᵀ/√d)V mixes values by query–key match. Causal masking restricts the mixing to the past; multi-head runs the same mechanism in parallel low-dimensional subspaces. The learner must be able to produce this from raw tensors, not recognize it in a library.

Learner prerequisites: l4-embeddings-lm (gold-track): embedding tables, autoregressive factorization, softmax/temperature; matrix multiplication as batched dot products (L2); trained MLP LM in PyTorch (Karpathy v2–v3 lineage); comfortable with tensor shapes and broadcasting.

What beginners commonly misunderstand:
- Q/K/V feel like three mysterious inputs; in self-attention they are three learned linear projections of the SAME x — the "soft dictionary lookup" framing collapses the mystery.
- Attention weights are activations, not parameters — they are recomputed per input (learners hunt for "the attention matrix" in state_dict and don't find it).
- Why /√d: at d≈256+, unscaled logits have variance ≈ d, softmax saturates to one-hot, gradients die. This is checkable, not folklore (the node's ablation exercise does exactly that).
- Masking must set logits to −∞ BEFORE softmax (zeroing probabilities after breaks normalization); many first implementations mask after and get silently-wrong distributions.
- Multi-head ≠ the same attention repeated h times on full vectors; it is h attentions on d/h-dim projections, concatenated — subspace routing, not ensemble.
- The averaging-with-lower-triangular-matmul trick (Karpathy's "mathematical trick") is where most learners report the mechanism finally clicking (see community evidence).
